# RaceDay System (PROG6212 - Part 1)

## About RaceDay
RaceDay is an event management platform built for the South African road running, walking, and cycling community. It streamlines the creation and management of events, categories, enrolments, and result tracking.

## System Roles
The system accommodates two primary roles:
1. **Organiser**: Responsible for creating and managing events, configuring race categories (e.g., 5km, 10km, Half Marathon), and recording race results for participants.
2. **Participant**: Can browse available events, enroll in specific categories, and view their personal performance history.
